# Mathe-Mitschrift

Web-App, die im Matheunterricht zuhört, alles live transkribiert und daraus pro Stunde Notizen, Formeln, Hausaufgaben und Übungsaufgaben erstellt.

- Öffnen: https://tgg-8.github.io/Contend-creation-/
- Als App installieren: im Browser-Menü „Zum Startbildschirm hinzufügen“ bzw. „App installieren“.
- Spracherkennung: Chrome, Edge oder Safari (braucht Internet).
- Optional: Anthropic-API-Schlüssel in den Einstellungen für ausführliche Notizen mit Claude.
- Alle Daten bleiben im Browser des Geräts.
