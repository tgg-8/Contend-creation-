# Was du selbst noch erledigen musst

## In Metricool
- [ ] **Google Drive in Metricool verknüpfen** (Einstellungen > Verbindungen / Integrationen). Ohne das kann Metricool die Videos aus Drive nicht übernehmen.
- [ ] **Pinterest-Board „Sprinttraining“** anlegen (oder mir sagen, welches Board die Pins bekommen sollen).
- [ ] In 1–2 Tagen prüfen, ob die Statistiken angekommen sind. Dann wiederholen wir Phase 1 mit echten Zahlen.
- [ ] Optional: prüfen, ob dein Instagram-Konto ein Creator- oder Business-Konto ist. Bei Business kann Metricool auch Instagram-Sounds setzen.

- [ ] Python und ffmpeg installieren (README, Schritt 1.2)
- [ ] Projekt holen, `pip install -r requirements.txt`, `.env` anlegen (README, Schritt 1.3 und 1.4)
- [ ] **Testlauf mit einem echten Clip** (README, Schritt 2) und mir sagen, wie Schnitt und Untertitel wirken
